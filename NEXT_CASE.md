# How to Add the Next Case Study

When I finish a new project, I will add it to my portfolio using the same three-part structure:

1. **Problem** — What problem was I trying to solve, and why did it matter?
2. **What I did** — What approach, tools, models, and key decisions did I use?
3. **What came of it** — What was the result, what did I learn, and what would I improve next?

### Steps to add it

1. Choose the strongest completed project.
2. Write the case study using the Problem → What I Did → What Came of It structure.
3. Add the project to the Projects section of my portfolio.
4. Add a dedicated project details page if needed.
5. Add relevant GitHub/demo links and screenshots.
6. Check the page on desktop and mobile.
7. Deploy the updated portfolio and verify the live page.
