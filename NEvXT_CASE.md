# How to Add the Next Case Study

## Where it will go

The next case study will be added to the **Projects** section of my portfolio, with a dedicated project details page following the same visual identity and case-study structure as my existing work.

## The three-beat structure

Each new case study will follow this structure:

### 1. Problem

Explain the problem, why it mattered, and what decision the project was trying to support.

### 2. What I Did

Describe the approach, tools, important decisions, and implementation steps.

### 3. What Came of It

Show the results, what I learned, the limitations, and what I would improve next.

## Steps

1. Finish and validate the project.
2. Write the case study using Problem → What I Did → What Came of It.
3. Add the project to the Projects section.
4. Create or update its project details page.
5. Add relevant screenshots, results, and links.
6. Check the page on desktop and mobile.
7. Deploy the updated portfolio.
8. Verify that the live project page works correctly.

## Future Updates

I will keep the existing portfolio structure, visual identity, and writing style so that future case studies can be added without rebuilding the portfolio.
